# KPM Primary Textbook Reference Materials

This directory holds official Ministry of Education (KPM) textbooks used for teacher and AI curriculum alignment.

## Storage Notice
- Large textbook PDF files (`*.pdf`) are **gitignored** to prevent repository bloat and avoid GitHub file-size limits.
- For local development, place the corresponding KPM textbook PDFs here:
  - `BUKU TEKS MATEMATIK TAHUN 1 JILID 1.pdf`
  - `Buku Teks Matematik Tahun 2 Jilid 2.pdf`
  - `Buku Teks Matematik Tahun 3 Jilid 2.pdf`
- In production, these should be hosted via an S3 / cloud object storage bucket or linked to official KPM digital portals.
